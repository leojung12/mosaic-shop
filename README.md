# MOSAIC Shop

MOSAIC 빌드팀 판매 사이트. 작업 규칙은 `CLAUDE.md` 참고 (Claude Code·Codex가 자동으로 읽음).

## 처음 한 번

1. GitHub 가입 후 팀 저장소 초대 메일 수락
2. 작업할 위치에서 터미널 열고 `claude` (또는 `codex`) 실행
3. 아래처럼 요청

```
이 GitHub 저장소를 내 컴퓨터로 받아줘: (저장소 주소)
받은 다음 그 폴더로 들어가서 CLAUDE.md 읽고 내 담당 파일이 뭔지 알려줘. 나는 (내 이름)이야.
```

## 매일 작업 루틴

1. 시작할 때: `최신 버전 받아와줘`
2. 내 담당 파일만 수정 요청
3. 브라우저에서 확인 (`index.html` 더블클릭)
4. 끝낼 때: `지금까지 한 거 커밋하고 푸시해줘`
5. 몇 분 뒤 Vercel 링크에서 반영 확인

## 막힐 때

- 에러 메시지는 통째로 복사해서 붙여넣기
- 충돌 났다고 하면 아무것도 누르지 말고 화면 캡처해서 빌드팀 톡방에 공유
- 30분 이상 진전 없으면 톡방에 질문
